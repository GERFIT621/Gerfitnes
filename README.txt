GitHub repository-ийн үндсэн (root) хэсэгт эдгээр 3 файлыг байрлуулна.
GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root) → Save.

Энэ нь iPhone болон Android browser дээр ажиллах PWA прототип. iPhone дээр Safari → Share → Add to Home Screen.
Бүртгэл одоогоор тухайн төхөөрөмжийн browser-д хадгалагдана; хэрэглэгчийн аккаунт/үүлэн синк байхгүй.
Хоолны хэсэг нь ерөнхий дадлын зөвлөмж бөгөөд баталгаажсан калорийн сан биш.
